# Smart-Customer-Relationship-Management-System
A console-based Customer Relationship Management (CRM) system developed in C++ that helps manage customer information efficiently using file handling.

Features
Secure login authentication
Add new customers
View all customers
Search customer by ID
Modify customer details
Delete customers
Phone number validation
Email prefix validation
Customer status management (Lead, Active, VIP)
Smart analytics dashboard
Persistent data storage using text files
Technologies Used
C++
Object-Oriented Programming
File Handling
STL (Vector)
String Manipulation
